# 市場觀察（eco）

一頁看懂全球市場：氣氛、重點、各市場漲跌、趨勢圖表、總經、事件日曆，以及南山／台壽基金分類與推薦。
資料由 GitHub Actions 定時抓取並發布到 GitHub Pages，不依賴任何本機資料夾。

## 上線步驟（一次性）
1. 建立新的 GitHub repo，把本資料夾內容推上去（預設分支 `main`）。
2. Settings → Pages → Source 選 **GitHub Actions**。
3. Actions 分頁 → 「更新市場資料並發布」→ Run workflow → mode 選 `daily`。
   第一次會回補約 2 年歷史，需要一兩分鐘。完成後網址在該 job 的 deploy 步驟。
4. 之後全自動：平日 06:20 / 14:10 / 16:10（台灣時間）日更並寫入歷史，台股盤中每小時、美股盤中一次快照。

不需要任何 Secrets：Yahoo Finance、FRED 公開 CSV、Forex Factory 日曆皆免金鑰。

  行事曆：過期變暗、今天強調；已公佈當天不變暗；待公佈分「2 小時內」與「更早」；30 分鐘內顯示倒數。

## 基金功能
- 資料來源：兩家官網基金快搜（同一套 MoneyDJ 後端），每次日更時抓全部標的。
- 分類：`config/fund_themes.json`（規則式：名稱關鍵字 → 27 個小分類 → 6 個大分類〔股票｜成熟市場、股票｜新興與亞洲、產業與主題、債券、平衡與多重資產、貨幣與保守〕；另有 6 個風險階層：高風險、成長、平衡、收益、穩健、保守）。分錯了就改這個檔，不用動程式。
- 篩選：可依大分類、小分類、風險階層、幣別、類型、夏普值、年化波動、近 1 年報酬區間與關鍵字篩選。
- 推薦：每家每個階層挑 2–3 檔。條件：一般基金／境外基金、成立滿 3 年、規模不太小、非暫停申購；用夏普值、近 3 年報酬、波動、規模的百分位綜合排序，同一檔基金只留一個幣別／配息級別，並盡量讓主題分散。**這是規則整理，不是投資建議。**
- 追蹤：每天比對清單，顯示新增／下架；想長期追蹤某檔，把 `{"co":"tlife","k":"代碼"}` 加進 `config/fund_watch.json`（點基金「明細」可複製），會累積淨值走勢（`data/series/fund_nav.csv`）。
- 基金共同：先看六個大分類的合成走勢（代理 ETF 等權重），再看每個大分類內的小分類。把基金依類別彙整（新興市場、拉丁美洲、貴重金屬、印度、中國…），每類配一個公開 ETF 當大勢參考（`fund_themes.json` 的 `proxy`，在 `symbols.json` 的隱藏組 `fidx`），圖表與類別都能點開看新聞。
- 注意：官網可能擋掉機器人請求，抓不到時網站沿用上一版並在狀態列提示；基金與新聞只在日更時重抓，盤中快照沿用上一版（工作流程會先從已發布的網站還原）。

## 本機使用
- `python -m pipeline.run --offline`：用現有歷史資料重建網站（不連網）
- `python -m pipeline.run --mode snapshot`：連網抓最新價
- 開啟 `index.html` 即可（雙擊也行，資料另有 `.js` 備援，不需伺服器）
- Windows 可直接雙擊 `run_local.bat`（加參數 `daily` 會連基金與新聞一起更新，`offline` 只重算）
- 執行時會顯示處理進度：`[n/總數] 階段名稱（共 N 項）`，各階段逐項／每 25% 更新計數，最後一行是完成摘要與耗時
- 測試：`python -m unittest discover -s tests`

## 結構
- `config/symbols.json`：所有標的、分組、趨勢圖、燈號、FRED 序列（新增標的只改這裡）
- `config/events.json`：手動事件（選舉、央行會議等）
- `config/calendar.json`：行事曆分類、關鍵字規則、ICS 訂閱
- `pipeline/`：fetch（抓取）→ build（概覽/趨勢/總經）→ run（流程與退出碼）
- `data/series/`：歷史（會 commit）；`data/site/`：產出（不 commit，部署時打包）
- `assets/`、`index.html`：純靜態前端（Chart.js 已內附）

## 失敗處理
- 單一標的失敗：保留舊資料並標示「過期」；從未抓到的標的不顯示
- 超過一半失敗：不更新、不部署，網站維持上一版
- 價格單日跳動超過 40% 視為異常，拒收（VIX、美債殖利率除外）
- 網頁每 5 分鐘自動重讀資料；資料超過 36 小時未更新會在頂端標紅

## 規則式標示（不是預測）
- 今日氣氛：VIX 水位／單日跳升，加上美股、費半、台股中跌最深（或漲最多）的一個
- 環境燈號：5 個因子的 20 日趨勢 × 近 250 日相關方向

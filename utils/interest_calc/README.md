# 保單利率試算工具

學習／試算用，**不是報價，也不是對客戶的承諾**。實際保費與保價金以保險公司建議書為準。

## 開啟方式

| 方式 | 做法 | 商品範例怎麼載入 |
|---|---|---|
| 雙擊 | 直接開 `index.html` | 讀 `products/bundle.js`（新增 JSON 後要執行 `python build_bundle.py`） |
| 本機伺服器（建議） | `python serve.py`（只用 Python 內建模組，只綁 127.0.0.1） | 自動掃描 `products/*.json`，放進去、重新整理就出現 |
| 手動匯入 | 畫面上「匯入商品資料（可多選）」 | 一次選多個 JSON，進「我的範本」 |

> 為什麼雙擊要 bundle：瀏覽器不允許網頁讀取本機 JSON（file://），只能載入 `.js`，所以用 `build_bundle.py` 把 JSON 包成 `bundle.js`。

## 目錄結構

```text
interest_calc/
├─ index.html            頁面骨架（只放 HTML，載入下列檔案）
├─ css/style.css         樣式（亮／暗色自動）
├─ js/
│  ├─ util.js            通用小工具
│  ├─ defaults.js        常數、預設狀態、舊資料轉換（merge）
│  ├─ calc.js            純計算：折扣階梯、反推保費、逐年表、IRR、里程碑（可用 node 測）
│  ├─ storage.js         localStorage：情境、我的範本、最後一次內容
│  ├─ products.js        商品範本：載入／套用／另存／匯出／匯入
│  ├─ charts.js          SVG 折線圖
│  ├─ view.js            畫面渲染
│  ├─ paste.js           貼上建議書整張表 → 欄位對應
│  └─ app.js             事件綁定、啟動
├─ products/             商品資料（一個商品一個 JSON）＋ index.json、bundle.js（自動產生）
├─ tests/calc.test.js    計算核心測試（node tests/calc.test.js）
├─ build_bundle.py       產生 products/index.json 與 bundle.js
└─ serve.py              本機伺服器（products 即時掃描）
```

JS 用一般 `<script>`（不是 ES module），原因同上：file:// 不允許載入 module。載入順序有相依，見 `index.html` 底部註解。

## 新增一個商品範例

1. 開啟工具 →「① 商品資料」→ 貼上建議書逐年表 → 對應欄位，並填**保額**與**表定年繳保費（折扣前）** → 套用。
2. 在「② 繳費與折扣」設定折扣規則、繳別加成係數；填商品名稱。
3. 按「匯出商品資料」，得到一個 JSON。
4. 把它放進 `products/`。`python serve.py` 開啟 → 重新整理即可；雙擊開啟則先執行 `python build_bundle.py`。

商品 JSON 格式（`schema: twlife.ic.product/1`）：`{ schema, name, state }`，`state` 內有商品名稱、DM、折扣規則（`pct`／`amt`／`tier` 階梯）、繳別係數、基準保額／表定保費、逐年解約金／身故金／領回金。**不含**客戶的年齡與金額。

## 畫面功能備註

- **隱藏輸入區**：從「情境名稱」那一列起整段隱藏，改顯示簡易調參列（年齡／保額，寬螢幕時固定在畫面頂端）。
- **預設**：上方為簡易模式（隱藏輸入區，只留年齡／保額）、下方為「獲利狀況」表格。舊存檔只會被套用一次新預設，資料不動。
- **表格模式**：獲利狀況（年度／年齡／累計實繳／保價金／單利／複利IRR，整張表直接排在頁面上、不另設捲動區），或完整。
- **表格沒有「里程碑」欄**：10/20/30/40/50/60/65/70/80/90/100/110 歲的年齡、總報酬每達 50%／100%／150%… 的第一年用粗體標示；繳費期滿為粗底線；里程碑摘要仍在表格上方的卡片。
- **單利**＝總報酬(年化單利)，例 50%(4.5%)；**複利IRR**＝年化複利報酬率（IRR 本身就是年化）。
- 內插估值（商品資料沒有的年度）以灰色斜體標示。
- **底色**：每 5 個保單年度兩色交替；里程碑只用最右欄的標籤，整列不變色。
- **數值顯示一律無條件捨去**（金額到整數、% 到小數 1 位、倍數到小數 2 位）。只影響呈現：計算不變，每期保費仍依建議書四捨五入到整數；匯出的 CSV 是未捨去的原始數值。
- **RWD**：圖表依容器寬度（頁寬）繪製，視窗縮放時重繪；手機版單欄、表格可橫向捲動。

## 重要名詞

- **表定年繳保費**＝折扣前（建議書：首期表定保險費）；**實繳年繳保費**＝折扣後（建議書：首期折扣後保險費）。
- 三個輸入（保額／表定保費／實繳保費）擇一，另外兩個自動換算。
- 折扣階梯：同一個折扣依保費分段，只套用目前所在的那一段。

## 測試

```bash
node tests/calc.test.js
```

對照建議書（表定 39,266 → 實繳 38,088、各繳別 19,806／9,979／3,352、第10年解約金 150,875.23、祝壽金 1,234,209.96）與 DM 範例（表定 39,175 → 實繳 38,000）。
